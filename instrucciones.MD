# Instrucciones de Generación de Código con IA

## Prompt Utilizado
"Genera un proyecto en JavaScript (Node.js) para el control de acceso a un evento deportivo en consola.
Requisitos:
- Prohibido usar métodos de Array dinámicos (push, shift, splice, etc.). Usar únicamente arreglos de tamaño fijo con `new Array(tamaño)` e índices numéricos.
- Aplicar POO básica con módulos ES6 (Clases Asistente, ControlAcceso y módulo main).
- Validar edad mínima de 18 años.
- Validar aforo máximo (ejemplo: 5 personas).
- Calcular y mostrar al final la lista de personas ingresadas y el monto total recaudado.
- Utilizar métodos con parámetros de entrada."

## Pasos para ejecutar el proyecto
1. Clonar el repositorio: `git clone <URL_DEL_REPOSITORIO>`
2. Ejecutar con Node.js: `npm start` o `node main.js`
